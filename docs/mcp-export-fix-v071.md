# v0.7.1：校对后直接导出 PNG

## 用户反馈及代码确认

用户反馈核对网格和色号后，只看到保存工程，没有导出图纸。

核查当前源码：原来「导出 PNG」只在 `state.pattern != null` 时出现，而该状态依赖另外点击「确认矩阵并保存工程」。普通保存不产生 Pattern；重新打开工程也不会直接恢复已确认 Pattern。导出按钮又位于长预览及用量表下方，导致入口隐藏且容易把工程保存当作导出。

此外，核对底部图例不等于已经识别出格子矩阵；缺少逐格识别时必须明确提示，而不是只露出保存按钮。

## 本次修正

- 主导入页底部固定并列「保存工程」与「导出 PNG 图纸」，不在纵向滚动内容中，也不等待 Pattern 出现才显示。
- 原始小格校对页也提供同样的保存/导出操作，不要求先返回找隐藏按钮。
- 点击导出即确认当前已校对矩阵，生成不可变 Pattern 快照，再直接打开系统 PNG 文件保存位置选择器。无需先保存工程、无需旧的“确认矩阵并保存工程”中间步骤。
- 导出不自动保存可编辑工程，界面说明两者区别；工程可保留待确认以便续改，PNG 必须满足门禁。
- MARD 未确认、网格未确认、尚未逐格识别、还有多少待确认格，均在导出按钮下明确提示。条件不满足时按钮禁用；仅完成图例审核但还没有矩阵时提供「开始识别」快捷操作。
- 保留白豆/空格门禁。没有以自动接受全部建议或把白色都当 H2 的方式绕过校对。
- 保存器使用点击时的快照，预览、计数、PNG 仍共享 Pattern。取消文件选择和导出状态丢失有明确提示；成功后提示 PNG 已保存、工程需另存。
- 不改变自动网格算法、图例识别、色卡、工程 schema 或 PNG 渲染算法；不新增权限，不涉及灯板。

## 新版操作

1. 对齐网格并点「确认对齐」，确认 MARD 和底部图例。
2. 点击「按原网格逐格识别」或底部「开始识别」，再校对格子，把待确认清零。
3. 直接点击页面底部「导出 PNG 图纸」。
4. 在系统界面选择目录/文件名，点击保存；这一步才实际写出 PNG 文件。
5. 若要下次继续编辑，另点「保存工程」。不需为了导出重复保存工程。

打开旧工程后，不必重新识别已有矩阵；审核网格并处理剩余待确认即可导出。不要先卸载或清除数据，以免私有工程丢失。
