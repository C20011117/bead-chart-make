# v0.7.1 当前网格功能：先自动检测与对齐，再同屏人工审核

## 本轮范围

用户反馈 v0.6 的格子对齐太难，原图与移动/格距控件不能同时看到，并要求先自动识别多少列×多少行、自动对齐，再人工审核。继续只处理数字图纸，不开发灯板/蓝牙、拼豆计时或完成进度。

本轮实现的是本地几何视觉检测，不是把旧按钮改名为 AI，也没有接入云端大模型。先在真实输入上验证检测结果，再接入自动流程；不宣称通用图纸准确率或色号逐格全对。

## 检测算法及边界

`android-app/app/src/main/java/dev/pindou/pattern/chartimport/AutoGridDetector.kt` 为纯 Kotlin 核心：

1. 对最多 2048 长边的转正原图提取横纵暗线脊投影及覆盖支持度。
2. 分析重复周期，并综合倍频支持，避免把每 5/10 格的粗线当作单格；近似同分时优先短基频。
3. 针对缩放后非整数格距，通过谐波细化及加权拟合计算亚像素格距和相位/起点，不要求用户先框选主体或猜行列数。
4. 根据有支持的格线连续区域确定主体候选。成对浅底、居中字迹的外围带只作为疑似坐标，不作语义识别保证；保留未裁候选供人工审核。
5. 无可靠结果时返回失败，不把默认 64×64 当作检测成功；支持取消，不发布半成品。

初次探针发现缩放图误取粗线周期、128 格合成图误取倍频，新增回归后修正。最终原图、偏移、缩放和 8/29/64/128 合成图全部通过。

局限：对极低清、缺线、斜拍、异形或多张图纸拼接不保证检测成功；浅色字格边带可能与坐标相似，必须人工审核。分数是拟合证据，不是正确概率。没有专门训练模型，也不承诺仅凭一张样本泛化到所有图纸。

## 新操作界面和流程

- 新图片导入时自动分析整张原图，直接填入行列与区域，并自动打开独立的「网格自动对齐 / 审核」页面。
- 原图和网格占据弹性画布，工具栏及起点/格距/行列/确认控件固定同屏；该页面没有外层纵向滚动，不再把移动控件放在原图下方很远处。
- 自动结果出现后将视图聚焦到候选主体，仍能双指缩放、拖动、切回全图和隐藏覆盖线。
- 「框选」开关用于拖蓝色边界点；默认拖动只查看图片。起点、横格距、纵格距均在同屏底部微调，步长 0.01 / 0.1 / 1 转正预览像素。
- 「行列」在同屏展开输入；普通审核只需检查四角和范围后点「确认对齐」。
- 失败会保留现有手动参数并提示不确定，不伪造成功。重新自动检测会在成功后替换旧草稿；已有草稿时先提示，已保存工程不自动覆盖。
- 打开旧工程时保留其校准和色号修正，不自动重新检测而破坏成果；同屏审核后可继续，必要时用户主动重新检测。
- 自动结果不能直接导出。网格必须人工确认，色卡/图例确认和待确认格清零门禁仍在。底部图例识别、原始小格校对、白豆/空格区分保持原有严格规则。
